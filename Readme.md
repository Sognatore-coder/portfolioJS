### Рефакторинг и модернизация сайта-визитки. Стили полностью переведены на архитектуру препроцессора Sass (SCSS) с применением методологии БЭМ.
**Выполнил:** Беседин Кирилл Дмитриевич
**Группа:** ФИТ-241

## Скрипты сборки проекта
Для управления сборкой проекта настроены следующие npm-скрипты:
* `npm run sass:dev` — запуск компилятора Sass в режиме постоянного отслеживания изменений (watch mode);
* `npm run build` — финальная сборка сжатого и оптимизированного продакшн CSS-файла.

## Инструкция по запуску с нуля

1. Установите зависимости проекта (пакет компилятора Sass):
```bash
npm install
```

2. Запустите сборку стилей в режиме разработчика:
```bash
npm run sass:dev
```

3. Запустите ваш локальный веб-сервер (например, расширение Live Server в VS Code) для просмотра результатов.
